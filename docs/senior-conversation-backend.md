# 시니어 안부대화 서비스 - 구현 기여 및 문제 해결

## 1. WebSocket 질문 상태 관리

- **구현 배경:** 연속된 음성 대화에서 답변이 다른 질문이나 이전 질문 생성 요청에 연결되지 않도록 구분 필요
- **설계·구현:** NestJS Gateway에서 JWT 인증 후 질문 ID·생성 ID를 현재 상태와 대조 · 유효한 음성을 AI 분석 서버에 전달
- **결과:** 답변과 질문의 연결을 검증하고 분석 결과·다음 질문·TTS를 WebSocket 이벤트로 전달

[관련 커밋 — 음성 대화·분석 흐름 구현 ↗](https://github.com/2026-SMHRD-KDT-HealthCare-5/maeum-itda/commit/6a9e71aaacd3edc4f4495a5ca923a4a31971eea7)

## 2. 리포트·근거 대화 트랜잭션

- **구현 배경:** 리포트 점수만 바뀌고 근거 대화 연결은 이전 상태로 남으면 분석 결과와 근거가 불일치
- **설계·구현:** 두 정보가 함께 바뀌도록 리포트 갱신·기존 근거 연결 삭제·새 연결 저장의 **3개 작업**을 TypeORM의 **단일 트랜잭션**으로 처리
- **결과:** 실패 시 일부 변경만 남지 않도록 전체 롤백 구성 · 대화 원문은 유지하고 근거 연결만 교체

## 3. 답변 큐·분석 요청 중복 제어

- **문제:** 같은 질문에 답변을 덧붙일 때 분석·다음 질문 생성 요청이 각각 시작될 가능성
- **원인:** 녹음 한 건과 질문의 답변 완료를 같은 단위로 처리하면 추가 발화도 별도 분석 요청으로 전달
- **해결:** 추가 발화를 함께 분석하도록 질문별 답변 큐 도입 · **마지막 답변 후 10초** 대기하고 추가 답변 시 타이머 재시작 · 묶음 대표 요청만 분석 실행
- **검증:** 테스트 코드에 답변 순서·타이머 갱신·대표 요청 구분·대화 종료 시 다음 질문 생성 차단 조건 포함
